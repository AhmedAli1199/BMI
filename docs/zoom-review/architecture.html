BMI Notetaker - architecture and data flow

BMI Publishing's internal notetaker for its own staff's sales calls. All BMI services run in Docker on one server operated by Cybix; public traffic is HTTPS (TLS 1.2+) through a Traefik reverse proxy.

Connect Zoom (once per person)

  1. A signed-in BMI salesperson presses Connect Zoom in BMI Brain.
  2. The browser goes to Zoom's OAuth page; they sign in to their own Zoom and allow BMI Notetaker. Zoom redirects to https://bmi.rabtaai.com/api/zoom/callback with a code and a signed state (who they are, valid for 15 minutes).
  3. BMI Brain checks the state and passes the code to the notetaker service over HTTPS with its API key.
  4. The notetaker exchanges the code at zoom.us/oauth/token with the app's own keys, checks the scopes, reads GET /v2/users/me, and stores only the refresh token, encrypted (Zoom rotates it on each refresh). BMI Brain stores just the BMI user ↔ Zoom user ID link.

Join a Zoom call and write the notes

  1. For a Zoom meeting a connected BMI person is in (from their calendar, or a link they paste), BMI Brain books the notetaker with that person's Zoom user ID.
  2. The notetaker asks the meeting bot to join, on behalf of that user.
  3. As the bot joins, it asks the notetaker (signed request) for permission; the notetaker refreshes the user's token and gets an OBF token for that meeting from GET /v2/users/me/token. The bot joins with the Meeting SDK as "BMI Notetaker" and waits (up to 10 min) for the user to be in the call; it leaves when they leave.
  4. The audio and transcript are kept privately in the meeting bot's storage.
  5. The notetaker sends the transcript text to Gemini to write the notes.
  6. The notes go back to BMI Brain by a signed (HMAC-SHA256) webhook and show in Call notes. Disconnect in BMI Brain revokes the token at Zoom (POST /oauth/revoke) and deletes it. Removing the app in Zoom sends App deauthorized to the notetaker (checked with x-zm-signature): the sign-in is deleted and BMI Brain shows Zoom as disconnected.
