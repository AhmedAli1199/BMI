The Brain - character sketches

Three directions for the BMI Brain character. Each one is a single drawing with moods as settings (eyes, eyebrows, mouth, arms), so any expression costs nothing extra and it follows the app's colours, including dark mode. Pick a direction (or mix: e.g. A's body with C's glasses) and I'll finish it with the full set of moods and the gentle movement (blink, float, thinking wobble).

Moods shown: Happy · Thinking (while it looks things up) · Pointing (tips and the tour) · Celebrating (small wins) · Puzzled (errors, "not found") · Sleepy (empty lists). Last box: the same drawing on a dark screen.
