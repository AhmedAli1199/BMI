Connect your app to the Notetaker

Your app sends a meeting link; the Notetaker joins the call, records it, and sends back the transcript and written-up notes. About 10 minutes to connect.

  1. Create your app in the console. Open the console → Apps → New app. Give it a name, the address results should go to (step 4), the bot's name, the notes style, and your project's own Gemini API key (from Google AI Studio, on a project with billing on - the notes are written with it, so the cost lands on your project). You get three lines - copy them.
  2. Put the three lines in your app's server settings (its .env, or Dokploy → Environment): 
    NOTETAKER_URL={{PUBLIC_URL}}
NOTETAKER_API_KEY=nt_...
NOTETAKER_WEBHOOK_SECRET=whsec_...
  3. Send the bot into a call - one request with the meeting link (code below).
  4. Receive the notes - one route in your app that checks the signature and saves the result (code below). Then press Send a test webhook in the console to check it works.

Step 3 - send the bot

Send the meeting link. Add join_at and end_at to book it for later (the bot is held for you between them - an hour if you leave out the end), external_id (e.g. your calendar event id) so sending twice never sends two bots, and metadata for anything you want back with the results.

import os, httpx

def send_notetaker(meeting_url, title=None, join_at=None, end_at=None, external_id=None, metadata=None):
    r = httpx.post(f"{os.environ['NOTETAKER_URL']}/v1/meetings",
                   headers={"Authorization": f"Bearer {os.environ['NOTETAKER_API_KEY']}"},
                   json={"meeting_url": meeting_url, "title": title, "external_id": external_id,
                         "join_at": join_at.isoformat() if join_at else None,
                         "end_at": end_at.isoformat() if end_at else None, "metadata": metadata or {}},
                   timeout=20)
    if r.status_code == 422:              # a plain-language problem, e.g. "That doesn't look like a Meet or Teams link."
        raise ValueError(r.json()["detail"])
    r.raise_for_status()
    return r.json()                       # {"id": ..., "status": "scheduled", ...}
export async function sendNotetaker({ meetingUrl, title, joinAt, endAt, externalId, metadata = {} }) {
  const r = await fetch(`${process.env.NOTETAKER_URL}/v1/meetings`, {
    method: "POST",
    headers: { Authorization: `Bearer ${process.env.NOTETAKER_API_KEY}`, "Content-Type": "application/json" },
    body: JSON.stringify({ meeting_url: meetingUrl, title, join_at: joinAt?.toISOString(), end_at: endAt?.toISOString(), external_id: externalId, metadata }),
  });
  const body = await r.json();
  if (!r.ok) throw new Error(r.status === 422 ? body.detail : "The notetaker couldn't be sent");
  return body; // { id, status: "scheduled", ... }
}

When it's busy. All apps share the same bots. If none is free for your time - or your app has reached its own limit - the request is refused straight away with a plain message you can show (status 422), e.g. "The notetaker is already booked for 2 calls at 14:00…". To check first: GET /v1/capacity?start=…&end=… answers {"free": 1, …}.

Step 4 - receive the notes

Add a route at the address you gave the console. Check the signature (so nobody else can post fake notes), save the result, and answer 200. Anything else is retried for a few hours.

import hashlib, hmac, json, os, time
from fastapi import APIRouter, HTTPException, Request

router = APIRouter()

def notetaker_signed(body: bytes, ts: str, sig: str) -> bool:
    if not ts or abs(time.time() - int(ts)) > 600:
        return False
    expected = "sha256=" + hmac.new(os.environ["NOTETAKER_WEBHOOK_SECRET"].encode(), ts.encode() + b"." + body, hashlib.sha256).hexdigest()
    return hmac.compare_digest(expected, sig or "")

@router.post("/api/notetaker/webhook")
async def notetaker_webhook(request: Request):
    body = await request.body()
    if not notetaker_signed(body, request.headers.get("x-notetaker-timestamp", ""), request.headers.get("x-notetaker-signature", "")):
        raise HTTPException(401)
    msg = json.loads(body)
    meeting = msg["data"]
    if msg["event"] == "meeting.completed":
        save_notes(meeting["metadata"], meeting["notes"], meeting["transcript"])   # your code
    return {"ok": True}
// app/api/notetaker/webhook/route.ts
import crypto from "node:crypto";

export async function POST(req: Request) {
  const body = await req.text();
  const ts = req.headers.get("x-notetaker-timestamp") ?? "";
  const sig = req.headers.get("x-notetaker-signature") ?? "";
  const expected = "sha256=" + crypto.createHmac("sha256", process.env.NOTETAKER_WEBHOOK_SECRET!).update(`${ts}.${body}`).digest("hex");
  const fresh = Math.abs(Date.now() / 1000 - Number(ts)) < 600;
  if (!fresh || sig.length !== expected.length || !crypto.timingSafeEqual(Buffer.from(sig), Buffer.from(expected)))
    return new Response("Not allowed", { status: 401 });
  const msg = JSON.parse(body);
  if (msg.event === "meeting.completed") await saveNotes(msg.data); // your code
  return Response.json({ ok: true });
}

import express from "express";
const app = express();

app.post("/api/notetaker/webhook", express.raw({ type: "application/json" }), async (req, res) => {

The same delivery can arrive twice (that's how retries work). Use msg.id - or the meeting's id - to ignore ones you've already saved.

What you get back

EventWhen
meeting.status_changedEach step: scheduled → joining → waiting to be let in → recording → writing up the notes.
meeting.completedThe call ended and the notes are ready. Has the transcript and notes. (If your app has no Gemini key yet, notes is empty and status_detail says so.)
meeting.failedIt couldn't record, e.g. nobody let it in. status_detail says why, in plain words you can show people.
test.pingSent by "Send a test webhook" in the console.

Other things you can do

GET    /v1/capacity              how many more calls you could book for a time (?start=…&end=…)
GET    /v1/meetings              your recent meetings (add ?status=completed)
GET    /v1/meetings/{id}         one meeting, with transcript, notes and timeline
DELETE /v1/meetings/{id}         stop: a bot in the call leaves and the notes cover the call so far; one that hasn't joined is called off
GET    /v1/zoom                  is Zoom set up, and the Zoom app's client id for the sign-in link
POST   /v1/zoom/connections      finish "Connect Zoom" with the code Zoom sent back
DELETE /v1/zoom/connections/{zoom_user_id}   disconnect someone's Zoom

Full reference, with a "try it" button for every call: {{PUBLIC_URL}}/docs.

Good to know

  • Someone has to let the bot in from the waiting room, unless the meeting lets guests straight in.
  • Google Meet, Microsoft Teams and Zoom. For Zoom, each person connects their Zoom once (POST /v1/zoom/connections with the code Zoom sends back) and a Zoom booking gives zoom_user_id: Zoom only lets the notetaker in on behalf of a signed-in person who is in the call, and the recording ends if they leave.
  • The "may not be who they say" warning in Meet shows because the bot joins as a guest. A signed-in Google account for the bot removes it - ask the Notetaker admin.
  • How many calls at once: the bots are shared by every app (shown on the console's Overview), and an app can also have its own limit. Bookings over either are refused when you make them, not when the meeting starts.
  • AI costs: each app's notes are written with its own Gemini key, so they're billed to its own Google project. The console shows each app's calls, hours and AI tokens this month.
  • Lost your key? Console → Apps → New key (the old one stops working straight away).
  • Results not arriving? Console → Apps → Webhook deliveries shows each try and the problem; Resend sends it again.
